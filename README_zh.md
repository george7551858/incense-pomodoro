# 一炷香 · 蕃茄鐘

以線香為意象的極簡專注計時 Web App。點一炷香，看煙起香盡，在一念之間完成一段專注。

整個 App 是單一檔案 `index.html`，純前端、無需建置、無外部相依（字型透過 Google Fonts 載入），開啟即用。

## 功能

- **線香視覺**：以 Canvas 繪製線香燃燒、煙縷與灰燼，香盡即代表時段結束。
- **四種香段**：短香（15 分）、一炷香（25 分）、中香（45 分）、長香（60 分）。
- **蕃茄鐘模式**：可切換顯示剩餘時間，香盡後進入 5 分鐘休息。
- **今日紀錄**：以點數標記當日完成的香段，資料保存在瀏覽器 `localStorage`。
- **晝 / 夜主題**：宣紙暖色與夜間深色兩種氛圍。
- **點香 / 暫停 / 重燃**：輕觸畫面或按鈕即可操作。

## 使用方式

直接以瀏覽器開啟 `index.html` 即可：

```bash
# 直接開啟
open index.html        # macOS
xdg-open index.html    # Linux

# 或啟動簡易本機伺服器
python3 -m http.server 8000
# 瀏覽 http://localhost:8000
```

## 操作

| 動作 | 說明 |
| --- | --- |
| 輕觸畫面 / 點香鈕 | 點香開始，再次點擊暫停 |
| 重燃 | 重置目前香段 |
| 香段標籤 | 切換短香 / 一炷香 / 中香 / 長香 |
| 時鐘鈕 | 切換蕃茄鐘（顯示時間） |
| 晝 / 夜鈕 | 切換主題 |
